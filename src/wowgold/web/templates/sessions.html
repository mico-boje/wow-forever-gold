Recording a session
  1. Copy addon/WowGoldLogger into your WoW client's Interface/AddOns folder (once).
  2. In game: /wgl start gryphons hillsbrad (the note is optional). A small REC timer shows while it records; /wgl pause / resume for breaks.
  3. /wgl stop, then /reload (or log out): WoW only writes addon data to disk then.
  4. The hourly collector imports it, or press Import now.
